# 蝦皮取件體驗優化｜可操作原型

使用者介面設計課程作業。根據訪談找到的三個取件痛點（狀態難辨、門市難辨、條碼難找），重新設計蝦皮 App 的超商取件流程，並做成手機與電腦都能操作的網站。

線上版：https://ventus316.github.io/shopee-pickup-prototype/

## 三個情境

| 情境 | 任務 | 對應痛點 |
| --- | --- | --- |
| 一 | 從首頁「今日待取」看今天能拿幾件，到取件中心依門市出示條碼 | 狀態難辨、門市難辨 |
| 二 | 搜尋商品，結帳時自動帶入常用門市（平日公司、週末住家） | 門市難辨 |
| 三 | 收到到店推播，點通知直接打開整合條碼，一個條碼取全部 | 條碼難找 |

## 功能

- 首頁今日待取卡、取件中心（依門市分組、可取貨與運送中分頁）
- 門市包裹清單打勾、整合條碼與 QR Code、取完自動完成訂單
- 搜尋（紀錄、熱門、即時建議）、排序、篩選（物流、評價、出貨地、容量、價格）
- 商品頁、規格選擇、購物車、結帳（門市、付款方式、免運券、折價券、蝦幣折抵）
- 購買清單六種狀態：待付款、待出貨、運送中、可取貨、完成、取消（可付款、取消、評價、再買一次）
- 常用門市管理：新增學校等門市、更換、刪除、設定平日與週末的結帳預設
- 通知列表、到店通知開關（關閉時取件中心會提示）、App 內推播橫幅
- 聊聊、評價領蝦幣、蝦幣、錢包、優惠券、我的按讚

## 示範工具

電腦版左側（手機版在「我的 → 原型說明與示範工具」）：

- **物流推進一天**：待出貨 → 運送中 → 到店，到店時會發推播
- **切到鎖定畫面看推播**：模擬手機鎖定畫面上的蝦皮通知
- **重設所有資料**

資料只存在瀏覽器的 localStorage，不會上傳。

## 本機執行

```bash
python -m http.server 8765
```

再打開 http://localhost:8765 。因為使用 ES module，不能直接雙擊 `index.html` 開啟。

## 檔案

- `index.html`：外框與桌機側欄
- `css/style.css`：樣式
- `js/data.js`：商品、門市、初始資料
- `js/app.js`：狀態、路由、畫面與互動
- `img/`：商品照片（Unsplash）
